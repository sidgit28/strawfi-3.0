# Finx 2.0

**Finx 2.0** (Fintech Multiverse) is a prototype investment and stock tracking 
tool, built to explore persona-based user experiences in fintech applications.

🔗 Live demo: [strawfi.com](https://strawfi.com)

## Overview

The project lets users select an investor "persona" to personalize their experience, 
with the frontend and backend communicating through a simple REST API to manage 
persona data.
